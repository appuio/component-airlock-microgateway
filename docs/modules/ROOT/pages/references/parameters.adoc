= Parameters

The parent key for all of the following parameters is `airlock_microgateway`.

Api reference for Gateway API can be found here: https://gateway-api.sigs.k8s.io/reference/spec

Api reference for Airlock Microgateway CRs can be found here: https://docs.airlock.com/

== `namespace`

[horizontal]
type:: string
default:: `syn-airlock-microgateway`

The namespace in which to deploy this component.

== Example

[source,yaml]
----
namespace: example-namespace
----

== `gatewayparameters.spec.features.externalNameServicesAllowed`

[horizontal]
type:: boolean
default:: `false`

Note that this is only available from v5.0.0 see https://github.com/airlock/microgateway/releases/tag/5.0.0 and configurable since v4.8.6.

== Example

To set it on a specific instance.
[source,yaml]
----
instances:
  vshn-default-test-01:
    gatewayParameters:
      spec:
        features:
		  externalNameServicesAllowed: true
----

To set it on all instanes of an environment.
[source,yaml]
----
default:
  gatewayParameters:
    spec:
      features:
        externalNameServicesAllowed: true
----

== `default.gatewayParameters.defaults.customResponses`

Allows to set the local and upstream customResponses, see
https://docs.airlock.com/microgateway/5.0/index/api/crds/gateway-parameters/v1alpha1/index.html#gatewayparametersspecdefaultscustomresponses[Airlock Microgateway docs].

The first matching entry is used.
It is not possible to override an existing range of the defaults in an instance because the additional customResponse configurations are appended because it is an array.

For placeHolders see https://www.envoyproxy.io/docs/envoy/latest/configuration/advanced/substitution_formatter#config-advanced-substitution-operators[envoy substitution operators].

== Example

[source,yaml]
----
default:
  gatewayParameters:
    defaults:
      customResponses:
        local:
          - statusCodeCondition:
              matcher:
                exact: 401
            customResponseRef:
              name: "401"
          - statusCodeCondition:
              matcher:
                range:
                  from: 400
                  to: 499
            customResponseRef:
              name: "4xx"
  customResponses:
        "401":
          content:
            - contentType: text/html
              body:
                value: |
                  <!DOCTYPE html>
                  <html lang="de">
                  <head>
                      <meta charset="utf-8">
                      <meta name="viewport" content="width=device-width, initial-scale=1.0">
                      <title>Customer Error 401</title>
                      <style>
                          @media (max-height: 550px) {
                              body { overflow-y: auto; height: auto; }
                          }
                      </style>
                  </head>
                  <body>
                  <main>
                      <h1><span class="textcode">Error </span>401</h1>
                      <section>
                        <h2 lang="de">Access Denied</h2>
                        <p lang="de">You can't access this application.<br>
                        Additional info: <a href="https://support.customer.com">Support</a>.</p>
                      </section>
                  </main>
                  <footer>
                      REQUEST ID: %STREAM_ID%
                  </footer>
                  </body>
                  </html>
              headers: {}
        "4xx":
          content:
            - contentType: text/html
              body:
                value: |
                  %RESPONSE_CODE%
----

== `backendTLSPolicyCNP`

[horizontal]
type:: object
default:: `enabled: false`, `sourceNamespace: ""`

Configures the Espejote `ManagedResource` that turns Airlock Microgateway
BackendTLSPolicies and ExternalName Services from the `sourceNamespace` into
CiliumNetworkPolicies in the gateway instance namespace, so gateway pods can reach
external backends through Cilium's DNS/SNI egress enforcement.

When enabled for an instance, the component renders the ManagedResource, a
ServiceAccount, and the required Roles/RoleBindings into the gateway instance
namespace (and read access into the source namespace).
Requires an operating https://espejote.io[Espejote] installation and the
BackendTLSPolicy CRD (`x-openshift.microgateway.airlock.com/v1alpha3`).

=== `backendTLSPolicyCNP.enabled`

[horizontal]
type:: boolean
default:: `false`

Enables the BackendTLSPolicy to CiliumNetworkPolicy rendering for an instance.

=== `backendTLSPolicyCNP.sourceNamespace`

[horizontal]
type:: string
default:: `""`

The namespace where the ExternalName Services and BackendTLSPolicies live that
gateway pods need to egress to.
Must be set when `enabled` is `true`.

== Example

[source,yaml]
----
instances:
  my-gateway:
    backendTLSPolicyCNP:
      enabled: true
      sourceNamespace: my-app-namespace
----
